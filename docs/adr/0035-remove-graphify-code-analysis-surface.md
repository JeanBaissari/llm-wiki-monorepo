# ADR 035: Remove the graphify Code-Analysis Surface

- **Status:** accepted
- **Date:** 2026-09-11
- **Amended 2026-09-11:** graph-bridge package removed after owner approval
- **Supersedes:** ADR-0005 (two-file unified graph output)
- **Context:** `graph-engine` hard-depended on `@sentropic/graphify ^0.17.1` (`graph-engine/package.json:17`) while no graph-engine source file imported it. The dependency pulled a 239-package, ~606 MiB install closure including `ollama-ai-provider`, the `@ai-sdk/*` mesh, twelve `tree-sitter-*` packages and DB drivers (`pg`, `pgvector`, `neo4j-driver`, `@google-cloud/spanner`). The code-analysis path (`--code-analysis`, `merged`, `export-graph`) had no tests, no CI coverage, and no in-repo consumers; graphify also required Node ≥ 20 while the repo supports Node ≥ 18. The project's owner decision (2026-09) is that local-model machinery stays out of the default story: agents bring intelligence from outside, and the base install performs no model downloads.
- **Decision:** Remove the graphify surface end to end. Drop `@sentropic/graphify` from `graph-engine` and the optional peer from `graph-bridge`; delete `graph-bridge/src/ast-parser.ts`, the graph-engine type shim, the `merged`/`export-graph` CLI actions and `--code-analysis` flag, and the web-viewer `/api/graph/code` route + client toggle. Delete the graphify skill reference and prune promotion from SKILL.md/docs/legal notices. Regenerate both npm lockfiles; the closure disappears from fresh installs. `graph-bridge` itself remains in the tree (merger/semantic-edges) but has no default consumer pending a separate owner decision.
- **Consequences:** Easier: fresh installs shed ~606 MiB and 239 packages; no `@ai-sdk`/Ollama/tree-sitter/DB-driver supply chain; the graph surface is fully offline and deterministic (wikilinks + entities + communities). Harder: code-structure graphs from source ASTs are no longer available in-repo; anyone needing them must use an external tool and import the resulting data themselves. ADR-0005's two-file unified graph is retired.
