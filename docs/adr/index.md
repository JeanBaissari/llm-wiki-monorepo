# ADR Index

All Architecture Decision Records for the llm-wiki monorepo. Newest last. Numbers are canonical — the v0.4.0 and v0.5.0 PRD registries reserve them and they are never reused or renumbered.

| ADR | Title | Summary |
|-----|-------|---------|
| [0001](0001-discover-py-single-source-of-truth.md) | `discover.py` as Single Source of Truth for Wiki Structure | All tools discover wiki layout (pages/sources/logs/audits) through one module; auto-detects flat wikis and custom directory names. |
| [0002](0002-package-distribution-vs-import-name.md) | Package Distribution Name vs Import Name Separation | Distribution name and import name are separated so packaging constraints do not leak into the import path. |
| [0003](0003-oidc-trusted-publishing-with-digital-attestations.md) | OIDC Trusted Publishing with Digital Attestations | Releases publish via OpenID Connect workload identity with signed attestations — no long-lived PyPI tokens. |
| [0004](0004-templates-shipped-inside-python-package.md) | Templates Shipped Inside Python Package | Domain templates ship inside the Python package so `scaffold.py` works from any checkout without a separate templates install. |
| [0005](0005-two-file-unified-graph-output.md) | Two-File Unified Graph Output (GAP-4 Prerequisite) | Graph output is written as two files (nodes/edges + communities) to keep diffs reviewable and layouts stable. |
| [0006](0006-two-step-cot-ingest-with-sha256-caching.md) | Two-Step CoT Ingest with SHA256 Caching | Ingest runs Stage 1 analysis then Stage 2 generation; Stage 1 is cached by source SHA256 so re-ingests skip unchanged work. |
| [0007](0007-concurrency-control-wikilock-atomic-writes-sha256.md) | Concurrency Control — WikiLock + Atomic Writes + SHA256 Conflict Detection | Writes are atomic under a wiki lock, with SHA256-based conflict detection for concurrent agents. |
| [0008](0008-sqlite-fts5-search-with-sha256-freshness.md) | SQLite FTS5 Search with SHA256 Freshness Detection | Keyword search uses SQLite FTS5/BM25; index freshness is tracked by page SHA256 and stale pages are re-indexed. |
| [0009](0009-agent-native-provider-zero-apikey-ingest.md) | Agent-Native Provider for Zero-API-Key Ingest | LLM providers are pluggable and agent-native — ingest works with zero API keys when the agent supplies the model. |
| [0010](0010-mcp-server-stdio-python-sidecar.md) | MCP Server Architecture — stdio + Python Sidecar | The MCP server speaks stdio and delegates Python operations to a sidecar via `__dirname`-resolved script paths. |
| [0011](0011-inverted-entity-index-for-O1-link-suggestions.md) | Inverted Entity Index for O(1) Link Suggestions | `link_suggest` uses a dual-map inverted index so "which pages mention X but don't link to it" is O(1). |
| [0012](0012-community-verification-suite-nmi-ari.md) | Community Verification Suite — NMI/ARI Cross-Validation | Automated suite cross-validates Python vs TypeScript community detection across 7 topologies × 5 seeds; amended by ADR-0017 to exact parity (NMI/ARI == 1.0). |
| [0013](0013-modular-package-layout.md) | Modular Package Layout by Domain | Repo reorganized into domain packages (skill/, mcp-server/, graph-engine/, templates/, …). Supersedes the 2026-07-04 "Acceptance Criteria" companion (merged into this ADR, deleted 2026-08-09). |
