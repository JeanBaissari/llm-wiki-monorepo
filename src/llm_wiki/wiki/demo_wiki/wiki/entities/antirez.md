# Salvatore Sanfilippo

Salvatore Sanfilippo, known online as antirez, created [[redis|Redis]] and led its
development for its first decade.

## Contributions

Beyond the server itself, antirez wrote the [[sds|Simple Dynamic Strings]] library
that underlies Redis's string handling, and designed the
[[lua-scripting|Lua Scripting]] interface for atomic client operations.
